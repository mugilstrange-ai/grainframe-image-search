# Grainframe — Image Search UI (Part 1)

Grainframe is a thoughtfully styled image-discovery interface, ready for real image searches in Part 2. I chose a terracotta-and-sage palette instead of a typical purple search-app theme to create a calm, editorial visual identity. I placed an illustrated introductory hero above the form so new visitors immediately understand what to do, and I added category chips and a friendly empty state to guide first-time exploration. The responsive results area uses `repeat(auto-fill, minmax(230px, 1fr))` so future image cards naturally reflow across screen sizes.

Open `index.html` in any browser to view the UI. Search and category buttons are intentionally inactive until Part 2.
